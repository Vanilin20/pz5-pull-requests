# pz5-pull-requests

Спільний репозиторій пари для Практичного заняття № 5 «Pull request і рецензування в команді».

**Проєкт:** ядро (`CoffeeGo.Core`) застосунку попереднього замовлення кави CoffeeGo — бібліотека класів на C# / .NET 8.

**Учасники:**
- Оліферук Іван (@Vanilin20) — власник репозиторію
- Котяш Андрій (@k0t1kk-0) — collaborator

## Процес роботи (GitHub Flow)

1. Задача — картка на дошці / issue.
2. Гілка під задачу: `feature/<коротка-назва>` або `fix/<коротка-назва>`.
3. Атомарні коміти в наказовому способі (`feat: add …`, `refactor: extract …`).
4. Pull request у `main` за шаблоном, рецензія партнера, щонайменше 1 approval.
5. Злиття через **Squash and merge**, гілка видаляється.

Пряме відправлення змін у `main` заборонене правилом захисту гілки.
